# Computer Vision

This repository contains five comprehensive projects covering the fundamental and advanced techniques of Computer Vision. Each module solves a set of challenges ranging from image geometry to neural-based perception.

## Projects Overview

### 1. Dense Stereo Correlation & Basic Image Processing
* **Topics:** Image filtering, image transformations, and disparity map estimation using correlation techniques for stereo vision.
* **Goal:** Depth estimation through dense stereo matching and disparity maps.

### 2. Parameter Estimation with RANSAC
* **Topics:** Robust estimation, outlier rejection, and geometric model fitting.
* **Goal:** Using the **RANSAC (Random Sample Consensus)** algorithm to estimate transformations despite noisy data or outliers.

### 3. Hand-Engineered Features & Planar Objects Recognition with SIFT
* **Topics:** Keypoint detection, descriptors, and feature matching.
* **Goal:** Implementing **SIFT (Scale-Invariant Feature Transform)** for robust object recognition and matching between different views of planar surfaces.

### 4. Deep Learning for Computer Vision
* **Topics:** Convolutional Neural Networks (CNNs), architecture design, and transfer learning.
* **Goal:** Solving classification and detection tasks using modern deep learning frameworks (PyTorch/TensorFlow).

### 5. Augmented Reality from Planar Templates
* **Topics:** Homographies, camera pose estimation, and 3D projection.
* **Goal:** Projecting virtual 3D objects onto a real-world video stream based on a planar template or marker.

## Tech Stack
* **Language:** Python
* **Format:** Jupyter Notebooks

### Key Libraries
* **Core Computer Vision:** OpenCV (cv2), Scikit-Image (skimage) (transform, filters, morphology, restoration).
* **Deep Learning & AI:** TensorFlow, Keras, PyTorch, TensorFlow Hub, Ultralytics YOLO (Object Detection).
* **Machine Learning & Analytics:** Scikit-Learn (sklearn) (RANSAC, Logistic Regression, Train/Test Split, Standard Scaler).
* **Numerical & Scientific Computing:** NumPy, SciPy (ndimage), SymPy (Symbolic math), Math.
* **Visualization & Interaction:** Matplotlib, MPLD3 (Notebook interactivity), IPython.display, PIL (Pillow).
* **GUI & Widgets:** Ipywidgets (Sliders, Checkboxes, Buttons for interactive simulations).

## AI Relevance
* **Robotics & Navigation:** Stereo vision and RANSAC are essential for spatial awareness.
* **Industrial Inspection:** SIFT and AR techniques are widely used in quality control and remote assistance.
* **Foundation of Modern AI:** Deep Learning for CV is the basis for technologies like facial recognition, medical imaging, and self-driving cars.
